# Latest React Native compatibility app

This minimal app exercises `@fibricheck/react-native-camera-sdk` on React Native 0.87.0 using
Fabric. RN 0.87 is the newest explicitly tested version, not the package's maximum supported
version.

The SDK is injected from the repository root with Yalc. See the parent compatibility README for
the refresh and build commands.

Use `yarn start`, `yarn android`, or `yarn ios` to run the app.
